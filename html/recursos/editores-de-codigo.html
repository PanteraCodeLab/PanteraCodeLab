editores de código

CodeBlocks

Los editores de código permiten... editar código. Existen muchos editores de código, sin embargo el que se estará usando en la clase es CodeBlocks. Aquí unos tutoriales de cómo instalarlo. CodeBlocks es muy completo y fácil de usar, he ahí la razón por la cual es seleccionado para el desarrollo del curso.

CodeBlocks es algo conocido como un IDE (Integrated Development Enviornment o Entorno de Desarrollo Integrado), es decir, aparte de ser un editor de código contiene compilador, depurador, extensiones, configuraciones, entre otros.
